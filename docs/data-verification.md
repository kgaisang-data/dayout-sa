## Verification rules

- A venue must have a current source URL before it is made active.
- Official prices are preferred. Where menus or event prices vary, DayOut uses a clearly labelled planning estimate.
- `local_business = true` is reserved for independently operated/local businesses, locally guided experiences, markets supporting small traders, or comparable local economic activity.
- `hidden_gem = true` is used selectively for lesser-known/local experiences; it is an editorial discovery tag, not a quality ranking.
- `last_verified` is refreshed when a record is reviewed against its source.
- Opening-hours data is optional because DayOut does not yet ask the user for a date/day. Users should confirm availability before travel.
